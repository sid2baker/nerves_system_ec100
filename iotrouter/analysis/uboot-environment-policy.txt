The exact binary links one ENV_BLK driver with load and save callbacks.
Its non-redundant 32 KiB range is byte offset 0x003f8000 of the boot
device. The independently captured range is entirely zero and has no
valid environment CRC, so this unit boots compiled defaults. saveenv
would persistently modify the pre-partition area and must not be used.
No fw_env.config is authorized; production slot state belongs in the
separately reviewed misc metadata design.
