The exact captured function first copies the FDT /chosen/bootargs at
0xb09e8a8c. It then loads the literal pointer to the embedded command line at
0xb09e8a90 and unconditionally calls the same strscpy routine at 0xb09e8a98.
Linux 6.1 drivers/of/fdt.c implements this sequence for CONFIG_CMDLINE_FORCE;
the default branch tests for an empty command line and the EXTEND branch
concatenates instead. Therefore transient U-Boot bootargs cannot select NFS
root with this exact stock kernel. Runtime symbols confirm that the same normal
kernel can load and unpack an initramfs, allowing a RAM-root /init without
changing the forced command line.
